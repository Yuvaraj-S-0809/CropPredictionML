Trained model weights (`best_crop_model.joblib`) are automatically downloaded from the official [GitHub Release v1.0.0](https://github.com/Yuvaraj-S-0809/CropPredictionML/releases/tag/v1.0.0) upon first run of `app.py`.

### Direct Download:
- [best_crop_model.joblib (9.68 MB)](https://github.com/Yuvaraj-S-0809/CropPredictionML/releases/download/v1.0.0/best_crop_model.joblib)

Place the file inside this `models/` directory if running offline.
